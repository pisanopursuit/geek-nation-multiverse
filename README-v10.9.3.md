# Geek Nation Multiverse 10.9.3

## My Universes workflow

- The member-navigation **My Universes** link now opens `universe/my.php`.
- The page separates universes the member follows from universes they created.
- It includes **Find Universes** and **Create Universe** actions.
- Joined, created, and pending totals appear at the top.
- Universe Engine remains an administrator-only management tool under Administration.

No database upgrade is required.
