# Geek Nation Multiverse v10.6 — Role-Aware Dashboard

This release replaces the legacy member dashboard with a responsive personal convention headquarters.

## Included
- Profile completion and account shortcuts
- Joined universe, event, course, and collectible summary stats
- Quick actions that adapt to installed modules and existing user content
- Automatic artist, booth, event-host, instructor, collector, company, and brand widgets
- Upcoming registered events and current Academy progress
- Empty states for roles the member has not activated
- Administrator shortcuts for admin users

No database upgrade is required. The dashboard reads the existing platform tables and safely falls back when a module is not installed.
