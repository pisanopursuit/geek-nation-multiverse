# Geek Nation Multiverse V6 — Events

## Install
1. Upload the Website folder over the current V5.2.7 site.
2. Sign in as an administrator.
3. Open `upgrade-events.php` and click **Install Events**.
4. Open **Event Admin** to approve events or generate six demo events.

## Included
- Public event directory and event pages
- Event creation and owner dashboard
- Event management tabs: overview, details, schedule, speakers, attendees, relationships, media, settings
- Public RSVP, capacity, and waitlist behavior
- Physical, virtual, and hybrid locations
- Links to companies, brands, booths, and universes
- Administrator approvals and featured events
- Demo event generation
- Event views table for analytics foundation

Live ticket payments, recurring events, comments, notifications, and expanded media uploads remain future work.
